1. Executive overview

Mod Alpha connects to an investor's existing broker account, reads MF/ETF holdings, and recommends the best date(s) each month to invest instead of a fixed SIP date — with optional one-tap order placement where the broker API allows.

MF + ETF
In scope at launch
1–2 dates
Smart purchases per fund / month
Extra Earnings
Shadow portfolio vs fixed SIP date

Two scenarios in this document Scenario A (Standard): Built for scale from day one — EKS, Multi-AZ, warm DR, multiple broker order APIs, LLM explanations, daily AA refresh.
Scenario B (Cost-Optimized): Lean launch stack — ECS/single-region, Zerodha-only orders, push-first notifications, weekly AA for inactive users, no LLM at v1. Scale when revenue justifies it.

2. Benchmark: returns.trade → Mod Alpha

returns.trade is a SEBI-registered, NSE-empanelled algo platform for stocks and F&O. Mod Alpha applies the same category of product — AI/systematic investing on the user's own broker account — to mutual fund and ETF SIPs.

3. Website AI features (SIP-focused)

The Mod Alpha website is not just marketing — it showcases AI capabilities, builds trust with verifiable performance, and drives app installs. Inspired by returns.trade's transparency + automation narrative, adapted for long-term SIP investors.

AI SIP Timing Demo

Interactive widget: user picks a fund + monthly amount → site shows simulated smart dates vs fixed-date SIP over 5 years using historical NAV (clearly labeled "illustration, not advice").

Extra Earnings Preview

Public backtest dashboard: "If you had followed Mod Alpha dates on Nifty 50 Index Fund since 2020…" — PaRRVA-verified where used in marketing.

Smart Schedule Generator

Logged-out flow: enter fund name → AI generates next month's suggested dates (teaser); full schedule + execution requires app + KYC.

AI Explainability Panel

For each recommended date: plain-language rationale (volatility window, mean-reversion score) — optional LLM copy layer on top of deterministic model outputs.

Fund-ready Calendar

Visual monthly calendar with smart dates, fund-ready reminders, and NAV cut-off times — mirrors in-app experience on web for SEO.

Comparison Calculator

Fixed SIP date (e.g. 1st of month) vs Mod Alpha dates — side-by-side unit accumulation chart using historical data.

AI FAQ / Support Bot

RAG chatbot trained on compliance docs, FAQ, and product mechanics — never gives personalized investment advice without KYC.

Trust & Compliance Hub

SEBI IA registration, MITC, grievance officer, SCORES link, methodology whitepaper, model version changelog.

Recommended for launch

7. Side-by-side comparison

Scenario A

Standard — scale-first

  • EKS + Kafka + Aurora + TimescaleDB
  • 4 broker order APIs
  • LLM explanations + live AI website demos
  • Warm DR Hyderabad
  • Datadog + Shield Advanced
  • Daily AA for all users
  • Best for: funded team, aggressive growth, millions target from year 1
Scenario B

Cost-optimized — launch-first

  • ECS + SQS + RDS + S3 Parquet
  • Zerodha orders only; others deep link
  • Static AI demos; no LLM at v1
  • Backup-only DR
  • CloudWatch + Sentry
  • Tiered AA refresh
  • Best for: Dec 2026 launch, 50k–200k year 1, optimize burn

Recommended path

Launch with Scenario B. Migrate toward Scenario A using the scale-up triggers in Section 6. This matches the returns.trade playbook: prove the regulated AI category on one broker and one asset class (SIP/MF), then expand brokers and automation once unit economics work.
